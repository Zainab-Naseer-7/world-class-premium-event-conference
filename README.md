# SYNAPSE 2026 — World-Class Premium Event & Conference Website

A luxury, high-performance, agency-grade website for **SYNAPSE 2026** (*Global Tech, AI & Leadership Summit*), engineered with pure Vanilla HTML5, CSS3, and ES6+ JavaScript. Designed to look and feel like a multi-thousand-dollar project crafted by a top-tier international digital design agency.

---

## 🌟 Key Highlights & Design Philosophy

* **Visual Identity & Aesthetics**: Deep void navy backdrop (`#03060f`, `#050917`), electric indigo/violet gradients (`#6366f1`, `#8b5cf6`), cyber cyan accents (`#38bdf8`), and champagne gold highlights (`#f59e0b`).
* **Zero Dependencies & Zero Build Steps**: No `npm install`, no heavy frameworks, no build tools required. Double-click `index.html` in any modern web browser and it runs instantly with 60 FPS smoothness.
* **Instantaneous Performance**: GPU-accelerated CSS animations, responsive typography, and an automatic viewport intersection observer that pauses canvas background particles when scrolled out of view.
